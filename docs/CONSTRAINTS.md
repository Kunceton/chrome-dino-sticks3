# CONSTRAINTS — Chrome Dino @ M5Stack Stick S3

> Last reviewed: 2026-09-23 | 状态：默认值已按固件项目特点设定，待用户审批
> 本文件定义「什么算可以交付」。任何改动出现在 git diff 中被审查；禁止为了通过检查而削弱本文件。

## Floor（始终强制，无需工具）

- 无新抑制注释（`// NOLINT`、`#pragma` 压警告等）；编译警告必须修复而非压制
- 无未实现的桩（空函数体、TODO 占位实现、吞掉错误的空 `catch`/空错误分支）
- 无跳过/删除的测试（除非 commit message 写明原因）
- 源码中无任何机密信息
- **嵌入式专项 Floor**：
  - 游戏主循环内禁止动态内存分配（`new`/`malloc`）——障碍池、BGM 序列全部静态/栈分配
  - `game_logic` / `name_gen` / `storage` 逻辑层禁止 include 任何 M5/Arduino 头文件（保证 native 可测）
  - 硬件引脚/API 定义必须以官方文档核实为准，禁止凭记忆填写

## Enforced with numbers（有数字、有命令）

| 维度 | 规则 | 检查方式 | 时机 |
|---|---|---|---|
| 编译 | `pio run` 零错误零警告 | `pio run 2>&1 \| tee /tmp/build.log` | 每次提交前 |
| 逻辑测试 | `pio test -e native` 全绿 | PlatformIO native 环境 | 每次提交前 |
| 测试覆盖 | game_logic / name_gen / storage 核心分支 ≥80% | 测试用例清单对照 SPEC §8 | Task 收尾 |
| 帧率 | 游戏进行中稳定 ≥30 fps（sprite 推送无撕裂闪烁） | 烧录后帧计数日志 + 目测 | 烧录实测 |
| 内存 | 运行期 free heap 最低点 ≥ 50KB；10 分钟连续游玩 heap 无单调下降（无泄漏） | `ESP.getFreeHeap()` 定期日志 | 烧录实测 |
| 音频 | 默认音量 ≤70%（官方建议：电池供电下 >75% 可能过载重启）；SFX 播放不得打断/卡顿 BGM | 烧录试听 | 烧录实测 |
| 按键响应 | 按下到画面/声音反馈 <50ms | 串口时间戳日志抽测 | 烧录实测 |
| NVS 磨损 | 榜单/HI 分/名字只在结算/切换界面时写入，游戏循环内零 NVS 写操作 | 代码审查 + 日志 | 每次提交前 |

### 数字理由

- **≥30 fps**：人眼对横版卷轴流畅感的下限；240×135 RGB565 全帧约 65KB，SPI 推送带宽足够，无理由低于此值
- **heap ≥50KB**：ESP32-S3 内部 RAM 约 320KB，sprite 缓冲占 65KB，留 50KB 下限防碎片化和中断栈峰值
- **音量 ≤70%**：M5Stack 官方明确建议电池供电时音量低于 75%，否则大音量瞬时电流可能触发重启
- **<50ms 按键响应**：动作游戏手感底线，超过即感觉「飘」
- **NVS 循环内零写入**：Flash 擦写寿命约 10 万次，游戏中距离计分若实时写入会在几小时内磨穿一个扇区
