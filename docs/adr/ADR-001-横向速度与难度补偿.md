# ADR-001：横向速度按屏宽比缩放（v2，试玩后修订）

- 状态：v3 已决定（2026-09-25，取代 v2）
- 背景：原版画布 600 宽，StickS3 横屏 240（40%）。

## v1 决策（已废弃）

横向速度与纵向物理统一 ×0.9，障碍间距补偿难度。

## v1 为何被推翻

首版烧录试玩：横向 5.4→11.7 px/f 意味着穿越 240px 屏幕仅需 0.74s→0.34s，而原版穿越 600px 需 1.67s→0.77s——**视觉流速感是原版的 2 倍以上**，"恐龙跑得太快"。间距补偿解决不了流速感问题。

## v2 决策

- **横向速度按屏宽比 0.4 缩放**：2.4→5.2 px/f，穿越时长与原版逐帧一致
- 纵向跳跃物理保持 ×0.9（高度/滞空手感不变）
- 加速度 ×0.4（0.0004/f），达到满速的时间与原版相同（约 117s）
- 计分系数 ÷0.4（0.0625），分数随时间增长速率与原版一致（里程碑/昼夜节奏不变）
- 翼龙阈值映射：原版 8.5 → 3.4
- 障碍间距下限 = f（当前速度滞空位移）自动适配（jump_air_distance 已是速度的函数）

## 后果

- 跳跃滞空期间水平位移占屏比与原版一致（满速跳跃约跨 0.82 屏宽）
- SPEC §3.0 已同步更新

## v3 修订（二次试玩）

v2 把横向速度降到 0.4 后，「滞空位移 ÷（障碍宽+恐龙宽）」余量从原版 ~2.2× 跌到 ~1.1×，仙人掌簇物理上跳不过去（试玩确认）。纯降速破坏了原版的几何配平。

**v3 决策**：速度缩放取折中 0.55（起步 3.3 px/f），同时跳跃滞空从 34 帧加长到 42 帧（重力 0.34、初速 -7.1，顶点高度不变）。越障余量恢复到起步 1.6×（大株 2.2×）、满速 2.9×；视觉流速比原版快 37%，在可接受范围。障碍生成逻辑保持原版公式不变（簇解禁速度/间距/去重同比例映射）。
